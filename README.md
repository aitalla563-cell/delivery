# 🛵 التوصيل المجنون

لعبة مسلية بدون أسئلة: أنت موصّل طلبات، والزبون جيعان! وصّل 5 طلبات قبل أن ينتهي الوقت أو يغضب الزبون.

## التشغيل
افتح `index.html` في المتصفح (أو انشر المجلد على أي استضافة ثابتة). يعمل جيداً على الهاتف.

## كيف تُلعب
- الدراجة تسير تلقائياً وتتوقف عند كل عائق.
- كل عائق له تحدٍّ سريع:
  - 🚕 **طاكسي واقف:** بوّق بسرعة حتى يتحرك.
  - 🫏 **كروسة بحمار:** أوقف المؤشر في المنطقة الخضراء لتتجاوز.
  - 👮 **شرطي:** اختر الوثائق الصحيحة الثلاث.
  - 🕳️ **حفر:** بدّل المسار 3 مرات.
  - 🚌🐑🛒🚧 **طوبيس، غنم، بائع متجول، أشغال:** اختر الحل الأنسب.
- **حل سريع/ذكي** = +3 ثوانٍ وتوربو 🔥 لمدة 5 ثوانٍ. **حل عادي** = تكمل. **فشل** = تتعطل 3 ثوانٍ ويزيد غضب الزبون.
- غضب الزبون يرتفع مع الوقت (أسرع وأنت واقف). يمكنك الاتصال به مرتين في كل طلب لتهدئته.
- البقشيش يعتمد على الوقت المتبقي ومزاج الزبون (⭐ إلى ⭐⭐⭐).

## الملفات
| الملف | الدور |
|---|---|
| `index.html` | الشاشات |
| `style.css` | التصميم |
| `game.js` | محرك الطلبات والوقت والغضب والنتائج |
| `obstacles.js` | العوائق والتحديات (أضف عائقاً جديداً هنا) |
| `sounds.js` | المؤثرات الصوتية |

## التعديل
- عدد الطلبات والوقت والعوائق: `TOTAL`, `TIMES`, `COUNT` في `game.js`.
- سيناريوهات الاختيار: مصفوفة `CHOICES` في `obstacles.js` (`[النص، perfect|ok|fail، تعليق]`).
